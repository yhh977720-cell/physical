第01节力学 · 基础

先分清：质量、重力与平衡

先知道研究的是什么量，公式才有意义。

同一袋书，“有多少物质”和“被地球拉多重”是两回事

质量描述物体所含物质的多少，常用kg；重力是地球对物体的吸引产生的力，常用N。把书带到重力较小的地方，质量可以不变，重力却会变小。

G = mg

G：重力，N；m：质量，kg；g：重力与质量的比值，N/kg。

适用条件：本页例子按g = 10 N/kg估算；题目另给取值时按题目要求。

m = 2 kg的物体，G约为20 N。kg和N的含义不同，不能把“2 kg”直接当成“2 N”。

平衡看运动状态，不看外形是否水平

一个物体受到几个力时，要看这些力共同作用的效果。静止或做匀速直线运动，属于平衡状态。对可绕支点转动的杠杆，还要保证两个方向的转动效果相互抵消。

物体静止→可以处于平衡≠一定水平

倾斜后保持静止的杠杆，也可以平衡。实验中把它调到水平，主要是为了便于确定、读取力臂。

这一节抓住一句话质量用kg，重力用N；平衡由运动和转动状态判断，不能只看是否水平。

第02节力学 · 基础

功：力通过位移传递能量

先确认“哪个力，让哪个物体，沿什么方向移动”。

抬箱子时，你通过力把能量传给箱子

把箱子从地面抬到桌上，你向上用力，箱子也向上移动。力的作用伴随着沿力方向的位移，这个过程中力对箱子做功，能量发生转移。

对大小不变、方向与移动方向一致的力，作用距离越长，做功越多；同样距离，力越大，做功也越多。

W = Fs

W：这个力所做的功，J；F：力，N；s：沿这个力方向的移动距离，m。1 J = 1 N·m。

适用条件：本节先讨论恒力与位移同向的情况。

手提箱子站着不动

手虽然向上用力，箱子没有位移，手对箱子不做功。人感觉累，还涉及身体内部的能量消耗。

匀速水平背着书包

对书包的支持力向上，位移向前，两者垂直；这个支持力对书包不做功。上楼时有向上的位移，就会做功。

同一个过程，可以考察不同的力做的功

提升重物时，克服重力做的功为Gh；用机械拉绳时，拉力做的功为Fs。这两个式子里，力和距离分别属于不同对象。

W提升物体 = Gh

G：目标物体重力，N；h：目标物体竖直升高的高度，m；W：提升物体所需的功，J。

一个最基础的对应

重200 N的物体升高1 m，提升它所需的功是200×1 = 200 J。即使绕路或使用机械，仍须先看它最终升高了多少。

这一节抓住一句话算谁的力做的功，就配谁沿该力方向移动的距离。

第03节力学 · 基础

功率：把做功多少放进时间里比较

功描述转移了多少能量，功率描述转移得多快。

两个人都把相同的箱子抬到同一张桌上。都完成100 J的功，一个用5 s，一个用10 s。功相同，但前者每秒完成20 J，后者每秒完成10 J。

P = W / t

P：功率，单位W（瓦特）；W：功，单位J；t：时间，单位s。1 W = 1 J/s。

同一个字母W在这里有两种角色：公式里的W表示功；“20 W”里数值后面的W表示瓦特这个单位。看它的位置和含义。

图像为什么能看出功率？

在本卷的W-t直线图像里，横轴时间、纵轴功。相同时间内，线越陡，功增加越多，说明功率越大。不能只看某个点更高，就直接说全过程做功一定更多，还要看比较的时间。

P = Fv

F：与运动方向一致的力，N；v：沿力方向的速度，m/s；P：该力的功率，W。

适用条件：由W = Fs、v = s/t得到；匀速拉绳时必须用绳端速度。

这一节抓住一句话功是“多少”，功率是“多快”；比较快慢，一定要带上时间。

第04节力学 · 核心

机械能：运动与位置让物体有做功的能力

先分别看动能、势能，再判断它们的总和。

运动的球、高处的球、压弯的弹簧，都能引起变化

滚动的球能撞动木块，具有动能；高处的球能落下做功，具有重力势能；压缩的弹簧能弹起物体，具有弹性势能。

  • 动能与质量、速度有关：质量相同，速度越大，动能越大；速度相同，质量越大，动能越大。
  • 重力势能与质量、相对高度有关：在相同重力环境和高度参照下，高度相同，质量越大则重力势能越大；质量相同，高度越高则重力势能越大。
  • 同一个弹性物体，在弹性范围内，形变越大，储存的弹性势能通常越大。
E机械 = E动 + E势

E机械：机械能；E动：动能；E势：势能，包含题目涉及的重力势能或弹性势能。单位都为J。

两种“上升”，机械能的判断不同

物体被火箭带着加速上升：按本卷质量不变的模型，速度、高度都增大，动能和重力势能都增大，机械能增大；能量来自外部供能。

球被抛出后向上运动：若忽略空气阻力，球速度减小、高度增加，动能转为重力势能，机械能保持不变。

摩擦使机械能减少时，能量通常转成了内能，并没有凭空消失。判断能量是否守恒，要看研究的是哪种能量、哪些对象。

这一节抓住一句话先把动能和势能分开判断，再看总和；不要看到“上升”就套同一个结论。

第05节力学 · 难点

杠杆：力越远，转动效果越明显

从推门理解力臂，再理解平衡公式。

推门时，靠近门把手通常比靠近门轴省力

因为相同的力，在离门轴更远的位置、用合适方向作用时，更容易让门转动。描述这种“转动效果”的关键，既有力的大小，也有力臂。

力的作用线是沿力的方向通过受力点的直线。力臂是支点到这条直线的垂直距离。因此，力臂既与受力点有关，也与力的方向有关。

F1l1 = F2l2

F₁、F₂：动力和阻力，N；l₁、l₂：它们各自的力臂，m，两边也可统一用cm。

适用条件：杠杆平衡，两个力产生相反方向的转动效果；本卷常忽略杆重或已将其影响调平。

平衡表示两个方向的转动效果相等。假设阻力与阻力臂不变，动力臂越大，所需动力越小。动力臂长于阻力臂时省力，短于阻力臂时费力。

动手看：手离支点越远，需要的力怎样变？

理想杠杆：忽略杆重，右侧20 N，阻力臂2.5 m；左侧始终竖直向下用力，使杠杆平衡。

F × 2.0 = 20 × 2.5，所以F = 25 N。

图始终画成平衡状态。改变左侧力臂时，程序同时算出维持平衡所需的力。

杆秤的本质，也是同一条平衡关系

支点在手提的秤纽处，物体与秤砣分处两边。忽略秤杆、秤钩自重时，物重×物体力臂 = 砣重×秤砣力臂。

两边重力都等于质量乘g，可以约去g，得到m物l物 = m砣l砣。秤砣更远，产生的转动效果更大，就能平衡更重的物体。

容易混淆的地方

杆长不一定是力臂。只有在力垂直于杆等特定情形下，相应杆段长度才直接等于力臂；作图要从支点向力的作用线作垂线。

这一节抓住一句话杠杆平衡，是两边“力×力臂”的转动效果相等。

第06节力学 · 难点

滑轮：分担重力，要付出更长的绳端路程

先看谁在一起上升，再数哪些绳段在向上拉它。

绳子的两个基本约束

在理想模型中，绳子不可伸长；忽略绳重和滑轮摩擦，同一根绳各处拉力相同。滑轮组公式就来自这两个约束。

定滑轮

轴不随重物升降，能改变用力方向。理想情况下只有一段绳承担重物，不能省力。

动滑轮

轴与重物一起上升。常见动滑轮有两段绳向上拉它，每段绳分担一部分总重力，所以可以省力。

为什么是F = 总重力 ÷ 绳段数？

把“物体+动滑轮”看成一起运动的一组。匀速上升时，上下作用平衡。若有n段竖直绳，每段拉力F，向上的合力就是nF，须平衡向下的物重G和动滑轮重G动。

nF = G + G动　→　F = (G + G动) / n

F：自由端拉力，N；G：目标物重，N；G动：随物体上升的动滑轮重，N；n：有效承重绳段数，无单位。

适用条件：匀速提升，忽略绳重与摩擦；承重绳段按本卷图示竖直。若还忽略动滑轮重，才可简化为F = G/n。

为什么省力却要多拉绳子？

若两段承重绳各缩短h，才能让动滑轮升高h。这两段合计缩短2h，必须从自由端拉出2h的绳子。n段承重时，同理须拉出nh。

s = nh　；　v绳 = nv物

s：绳子自由端路程，m；h：物体上升高度，m；v绳、v物：绳端和物体速度，m/s；n：有效承重绳段数。

动手看：两段绳如何连接力、距离与效率

物重120 N，有效承重绳段数n = 2。匀速提升，忽略绳重和摩擦，保留动滑轮重。

拉力F 75 N

绳端路程s 2 m

有用功 120 J

总功 150 J

有用功占总功80%

绿色部分用于提升目标物体，其余部分用于提升动滑轮。图示运动距离经过缩放，不是按米作图。

容易混淆的地方

n不是滑轮个数。应看有几段绳直接向上支持动滑轮及重物；绳端若固定在动滑轮组上，并向上拉动滑轮组，也要计入。不同绕法的n可能不同。

这一节抓住一句话绳段多，单段分担的力小；同样升高h，绳端必须走nh。

第07节力学 · 贯通

效率：输入能量中，有多少完成了目标

区分任务、输入和额外消耗，公式会自然出现。

用滑轮提升货物时，你真正的任务是提升货物

货物重G、升高h，完成任务的有用功是Gh。拉绳力F、绳端路程s，输入给机械的总功是Fs。额外提升动滑轮、克服摩擦等，也要消耗输入能量。

W总 = W有用 + W额外
η = W有用 / W总 × 100%

三种W均表示对应的功，单位J；η是效率，无单位，通常用百分数。

适用条件：三种功对应同一次工作；这里以提升目标物体为任务。

机械效率高，表示输入的功中有用部分占比大。功率大表示做功快；省力表示需要的力小。这三件事比较的量不同，不能相互替代。

理想机械没有额外功，输入功等于有用功。实际机械有额外功，同样提升一个物体，输入功还会更多。这就是本卷“使用机械不能省功”的含义。

η滑轮 = Gh / (Fs) × 100% = G / (nF) × 100%

G：物重，N；h：高度，m；F：拉力，N；s：绳端路程，m；n：绳段数。

适用条件：第二式利用s = nh，仅用于本节所述滑轮竖直匀速提升任务。

把原卷滑轮综合题串成一条线

物重960 N，上升10 m，拉力600 N，n = 2，用时30 s。

  1. 目标端：有用功 = 960×10 = 9600 J。
  2. 动力端：绳端路程 = 2×10 = 20 m，总功 = 600×20 = 12000 J。
  3. 快慢：拉力功率 = 12000÷30 = 400 W。
  4. 占比：效率 = 9600÷12000 = 80%。

把600 N与10 m相乘，会把拉绳端的力和物体端的高度混在一起。

斜面也是同样的能量账

沿斜面拉同一物体到相同高度，路程L比高度h长，所以理想情况下可用更小拉力。匀速且拉力沿斜面时，总功FL、有用功Gh，效率为Gh/(FL)。L、h单位都为m，却代表不同的距离。

这一节抓住一句话先定目标，再找输入；有用功除以总功，才是机械效率。

第08节热学 · 基础

温度、内能、热量：从分子层面分开理解

这三个词相关，但描述的不是同一件事。

看似静止的水，内部的分子仍在不停地运动

物体里有大量分子，它们不停地做无规则运动，分子间也有相互作用。分子运动具有动能，相互作用涉及势能。这些微观能量的总和，就是物体的内能。

温度：表示冷热程度

通常温度越高，分子热运动越剧烈。但温度不是物体内部能量的总数。

内能：物体内部微观能量的总和

与温度、物质种类、质量、状态等有关。同种同温同状态的一桶水与一小杯水，桶里分子更多，内能通常更大。

热量：因温度差而传递的能量

热传递时，高温物体向低温物体传递能量，传递了多少叫热量，单位J。因此说“吸收、放出热量”，不说物体“含有热量”。

改变内能有两条常见途径

热传递：热水把能量传给较冷的杯子，水的内能减小，杯子的内能增大。没有外界做功等干预时，热量自然由高温一侧传向低温一侧；不能由谁的内能总量更大来判断方向。

做功：搓手、摩擦生热，或压缩气体，可把其他形式的能量转为内能；气体膨胀对外做功，也可使自身内能减小。

在初中近似下，两种方式都能改变内能，但原因不同：一个是因温差传递能量，一个是通过做功转移或转化能量。

容易混淆的地方

把整块物体抬高，增加的是其宏观重力势能，不是仅凭“抬高”就增加分子内能；物体整体运动的动能也不是内能中的分子热运动动能。

这一节抓住一句话温度看冷热，内能看微观能量总和，热量看热传递过程中传了多少能量。

第09节热学 · 核心

比热容：升高同样温度，需要付出多少热量

把“每千克、每升高1℃”理解透，就不用死记大小关系。

同样加热，水常常升温较慢

不同物质，要让相同质量升高相同温度，所需热量可能不同。比热容c表示单位质量某物质升高或降低1℃时，吸收或放出的热量。

水的比热容是4200 J/(kg·℃)，意思是：1 kg水升高1℃，需要吸收4200 J的热量。若质量变成2 kg，升温量仍为1℃，热量加倍；若升温量也加倍，所需热量再加倍。

Q = cmΔT

Q：温度变化对应的吸热或放热量大小，J；c：比热容，J/(kg·℃)；m：物体质量，kg；ΔT：温度变化量大小，℃。

适用条件：物态不变、比热容近似不变；升温ΔT = 末温−初温，降温取初温−末温。

同m、同Q→c越大→ΔT越小

比热容大，表示每升高1℃需要更多热量。在本题控制条件下，同样吸热后，它的温度变化反而更小。

动手看：吸热相同，为什么升温不同？

两种液体质量都为0.2 kg，初温都为20℃；不计散热，也不发生物态变化。每种液体分别吸收下面设定的同样热量。

水：c = 4200升温10℃

末温30℃

液体B：c = 2100升温20℃

末温40℃

c的单位均为J/(kg·℃)。条形长度表示温升，统一以40℃温升为满长；颜色只用来区分液体。

同样吸收8400 J，水升温10℃，液体B升温20℃。水的比热容较大，升温较慢。

初温不同，要看温升而非温度高低

两种等质量液体吸收相同热量：甲从10℃升到30℃，升20℃；乙从30℃升到40℃，只升10℃。

乙末温更高，但它升温更少，所以乙比热容更大，为甲的2倍。吸热多少由题设决定，不能从末温谁高直接判断。

加热图像的斜率为什么有用？

相同加热条件下，按本卷模型，同样时间吸热相同。质量相同而温度上升更快的液体，每升1℃所需热量更少，所以比热容更小。比较之前先确认质量和加热条件一致。

这一节抓住一句话先说什么相同，再比升温多少：同质量、同吸热，升温慢的比热容大。

第10节热学 · 难点

沸腾：吸了热，温度也可以不升高

公式有使用范围，算完数字还要回到真实过程。

温度不变，仍可能在吸收热量

标准大气压下，敞口加热水，到100℃后继续加热，水可以持续沸腾。只要液态水仍在，沸腾过程中水温基本不变，吸收的能量用于汽化等过程。

从微观看，水变成水蒸气涉及分子间距离和相互作用能的改变。热量并不都表现为温度上升，所以不能把相变吸热全套进Q = cmΔT继续算升温。

完整理解原卷的“实际升温”

300 g水，初温25℃，吸收1.008×10⁵ J，不计热量散失，标准大气压。

  1. 统一质量：300 g = 0.3 kg。
  2. 先做单纯升温估算：ΔT = Q/(cm) = 100800/(4200×0.3) = 80℃。
  3. 检查过程：25+80 = 105℃，超过敞口水在该气压下的沸点，不能把这个结果当实际末温。
  4. 按实际状态回答：末温100℃，实际升温100−25 = 75℃。

升到100℃需要4200×0.3×75 = 94500 J；剩余6300 J可用于汽化等过程。这里热量没有消失，只是没有继续表现为升温。

容易混淆的地方

不能把所有“水加热”都直接写成温升75℃。本例结论依赖初温25℃、标准大气压、热量足以到沸点，且液态水尚未全部汽化。换条件必须重新判断。

这一节抓住一句话先用公式估算，再检查物态和沸点；“吸热”不必然等于“升温”。

第11节热学 · 核心

热值：燃料能供多少能量

比热容描述物质升温的需要，热值描述燃料燃烧的供给。

热值q表示单位质量，或按题目约定单位体积的燃料，完全燃烧释放的热量。比如q = 1.4×10⁸ J/kg，表示每1 kg该燃料完全燃烧释放1.4×10⁸ J。

Q放 = mq　或　Q放 = Vq

Q放：燃料完全燃烧释放热量，J；m：燃料质量，kg；V：燃料体积，m³；q：热值，分别为J/kg或J/m³。

适用条件：看q的单位选形式；完全燃烧时使用。两种单位的q不能直接混用同一个数值。

c：比热容

问“这份物质升温，需要多少热？”对象通常是被加热的液体。常用Q吸 = cmΔT。

q：热值

问“这份燃料完全燃烧，能放多少热？”对象是燃料。常用Q放 = mq或Vq。

同样供能条件下，要完成相同任务，热值较大的燃料可能用得更少。燃料少了，并不表示热值变小；热值是燃料本身的特性，不由剩余多少决定。

两个质量，不能拿混

用燃气加热0.5 kg液体：cmΔT中的m指液体质量；mq中的m指消耗的燃料质量。写同一个字母，不表示它们是同一个物体。

若题设燃烧热量全部被液体吸收，才可令Q放 = Q吸。由此把“燃料供能”和“液体吸热”连起来。实际有散热时，液体吸热小于燃料放热。

容易混淆的地方

2 kg = 2000 g换算正确；但若热值仍用J/kg，乘法就必须用2 kg。若坚持用2000 g，热值也要同时换成J/g。数字与单位要成套改变。

这一节抓住一句话先辨供给还是需要，再辨对象；c管升温所需，q管燃烧可供。

第12节热学 · 难点

热机：把燃料释放的能量变成有用机械功

从能量流向理解效率，从工作循环理解转速。

燃料化学能→高温气体内能→活塞机械功

燃料燃烧后，气体温度、压强升高，气体推动活塞，对外做功。放出的总能量只有一部分成为有用机械功，其余会随排气、散热以及摩擦等离开有用输出。

η热机 = W有用 / Q放 × 100%
W有用 = η热机Q放

η热机：热机效率，无单位；W有用：输出的有用机械功，J；Q放：燃料完全燃烧放热，J。代入50%时用0.50。

单缸四冲程：四个阶段，只有一次主要对外做功

  1. 吸气：活塞向下，进气门打开。汽油机吸入汽油与空气的混合物；柴油机吸入空气。
  2. 压缩：活塞向上，气门关闭，对气体做功，气体内能、温度升高。
  3. 做功：燃烧后的高温高压气体膨胀，推动活塞向下，内能转化为机械能的一部分。
  4. 排气：活塞向上，排气门打开，排出废气，为下一循环准备。

其他阶段也可能有气体与活塞之间的功，但本卷“每循环对外做功一次”指做功冲程的主要输出。不能把“四个冲程”当成“四次对外做功”。

一个工作循环：4个冲程 → 飞轮转2圈 → 对外做功1次

这里的次数关系适用于单缸四冲程内燃机；多缸机需按题目重新处理。

从每秒做功次数推到每分钟转速

每秒做功20次 → 每秒飞轮转20×2 = 40圈 → 每分钟转40×60 = 2400圈，即2400 r/min。

先转换物理关系，再转换时间单位；不要一步凑数字。

这一节抓住一句话热机效率看能量去向；四冲程计数记住“四冲程、两圈、一次主要做功”。

第13节方法 · 贯通

实验：让看得见的现象回答真正的问题

先明确研究变量，再确定控制条件和观察指标。

实验里有三种不同角色

研究变量

想知道谁会影响结果。例如钢球动能是否受速度影响。

操作条件

为了改变研究变量而采用的手段。例如改变释放高度，来改变钢球到达水平面时的速度。

观察指标

用容易观察的现象间接比较看不见的量。例如用木块被推动的距离，比较钢球动能。

释放高度不同→碰撞前速度不同→木块移动距离不同

因此这组实验结论应写：质量一定时，钢球速度越大，动能越大。不能把操作用的“高度”直接填成这个实验研究的动能因素。

控制变量，是让比较公平

要研究速度，就保持钢球质量、木块和水平面等条件一致；要研究质量，就要让比较时的速度尽量相同。一次只改变准备研究的因素。

两个热学实验，观察方法不同

比较液体比热容

液体质量相同、加热方式和容器等条件相同，比较相同加热时间的温升。按实验模型，同时间吸热相同，升温小者比热容大。

在燃料充足、加热条件相同的情况下，不必额外要求燃料的总质量也完全一样。

比较燃料热值

用相同质量的不同燃料，分别加热相同质量、同种的液体。让燃料烧尽，再比较液体温升；在吸热条件近似相同的模型下，温升大说明该份燃料供热更多。

不以“同时间”为主要比较终点，而是以相同质量燃料完全燃烧为依据。

第19题自定义K，怎样从定义看关系

题目用“单位质量物质吸收1 J时温度变化的指标K”比较性质。由Q = cmΔT，在质量、吸热量分别相同的条件下，温度变化与c成反比，因此K与c成反比。

比较两种液体时，可写Kₐ/Kᵦ = cᵦ/cₐ。比热容大的液体，K较小。这里K是题目自定义的比较指标，不是温度单位开尔文；关键是按题目的定义建立关系。

实验操作也有物理原因

测滑轮组拉力：先看弹簧测力计量程、分度值和单位，再沿要求方向匀速拉动并读数。匀速让受力关系稳定；停下后摩擦状态可能改变，静止时的读数不能直接替代运动时的拉力。

组装加热装置：一般自下而上，先按热源和加热位置确定支架、容器高度，再安排温度计。温度计玻璃泡应与被测液体充分接触，不碰容器底壁，才能尽量反映液体温度。

这一节抓住一句话研究谁、改什么、控什么、看什么、得什么结论，五件事要对应。

第14节综合 · 难点

综合题：顺着能量与对象，把几个公式连起来

先找前后步骤之间不变或相等的物理量。

综合题难在连接，不只是公式更多

先画能量路线，确定每一步“输入是什么、输出是什么”。一个公式的结果，常常是下一步的已知量。要找的是物理关系，而不是把题目里所有数字随意相乘。

两辆汽车比较效率：先找到相同有用功

氢能源车消耗2 kg燃料，q氢 = 1.4×10⁸ J/kg，效率50%。汽油车在相同阻力下行驶同样路程，消耗10 kg汽油，q汽油 = 4.6×10⁷ J/kg。

  1. 氢燃料提供多少：Q氢 = 2×1.4×10⁸ = 2.8×10⁸ J。
  2. 其中多少用于做有用功：W氢 = 0.50×2.8×10⁸ = 1.4×10⁸ J。
  3. 两车之间靠什么连接：匀速行驶时，克服阻力做功为fL。相同阻力、相同路程，所以有用功相同，即W汽油 = W氢。
  4. 汽油提供多少：Q汽油 = 10×4.6×10⁷ = 4.6×10⁸ J。
  5. 求汽油机效率：η汽油 = 1.4×10⁸ ÷ 4.6×10⁸ ≈ 30.4%。

f表示阻力、单位N；L表示行驶路程、单位m。题中已有“相同”，可以直接建立相等关系，不必先算出f的具体数值。

“效率相差”和“相对提高”要分开

50%与30.4%的效率之差约为19.6个百分点；若按1个百分点精确，约20个百分点。相对提高率则是(50%−30.4%)/30.4%，约64%；用未四舍五入的原值计算更准确。原卷末问表述有歧义，应结合标准答案明确口径。

算完后，用三个检查把答案拉回物理情境

  • 单位：kg配J/kg；m³配J/m³；功率用J除以s。
  • 数量级：100800÷1260应为80，不会是0.8；科学计数法先算系数，再算指数。
  • 条件：水是否达到沸点；效率是否超过100%；有用功是否大于总功；所用距离到底属于物体还是绳端。

这一节抓住一句话综合题先画关系链；中间量接对，公式才能接对。

把理解落在这三件事上

读完一个知识点，能说清“研究哪个对象”“为什么会这样”“公式里的量如何对应”。解题时沿着关系走，答案出来后检查单位、数量级和条件。

按本次试卷涉及的初中力学与热学内容整理。公式均配有对象、单位或适用条件说明；互动演示采用文字标注的理想模型。数值显示按需四舍五入，定量结论不应直接套用到条件不同的情境。
